# 字间

一个单机 3D 拼词游戏。字母落在浮岛上，拼好的单词让拱门升起、桥梁逐块搭成、植物生长。晨光、青岚、余晖三关使用不同的字母与配色。主画面只保留关卡、剩余积木和必要控制。

## 运行

需要 Node.js 22.13 或更新版本。

```sh
npm install
npm run dev
```

打开 http://localhost:5173。项目 `.npmrc` 与锁定文件统一使用 npm 官方公开源 `https://registry.npmjs.org/`。

```sh
npm run build
npm run preview
npm test
npm run test:browser
```

## 玩法

每关有 24 块字母和六座拼词岛，两组 3 格、两组 4 格、两组 5 格。把积木拖进格子，或点击积木填入当前岛，也可直接输入键盘字母。点击空格子切换岛；数字 1～6 也能切换。正确的词自动完成，同一关内不能重复使用同一个词。

提示按钮按需显示常用词、中文释义与发音；“补一块”使用现有字母补一个位置。空格打开提示，再按空格补字。Backspace 或撤回按钮退回当前岛最靠后的字母；当前岛为空时，撤回最近完成的整个词，恢复其字母，场景里的建造也随之收回。

拼好三个词后中央门亮起，可点击门结束本关，剩余字母越少越好。全部用完会自动完成。没有倒计时、双人模式或排行榜。暂停菜单可重来、选关、查看玩法和学习记录。

横屏与竖屏分别安排岛屿布局；手机可使用屏幕字母键盘。滚轮可缩放。优先使用 Three.js WebGPU，初始化失败时回退 WebGL；无可用图形接口时仍可通过字母键盘操作。

## 词表

识别词表来自公开包 [word-list](https://github.com/sindresorhus/word-list)，其上游词表来自 atebits/Words。筛选 3～6 个英文字母后共 41,689 词，包含 GAP。当前关卡提供 3～5 格；更广的词表用于识别，提示与中文释义使用精选常用词，未覆盖的释义留空。

安装依赖后执行 `node scripts/build-lexicon.mjs` 可重新生成 `src/lexicon.json`。词表许可证见 `public/word-list-license.txt`。

## 学习记录

点击场景中的旋转晶球，或暂停菜单的“记录”，打开 AVA 4.0 分析。真实使用 `@antv/ava@4.0.0` 的浏览器 JavaScript 引擎执行 `source`、`schema`、`profile` 与本地固定 `query`，汇总每日拼词、平均用时和错误。无需 API 密钥，也不会发送练习数据。可导出 JSON。

练习记录沿用 `lexi-practice-v1`，保留最近 1000 次；进度和个人最佳剩余数使用 `lexi-islands-v3`。撤回再完成同一词，每关只记录一次。暂停、完成与分析窗口打开时，练习计时暂停。清除浏览器存储会清除这些记录。

## 验证

规则测试覆盖 GAP 与公开词表、三关完整解、字母守恒、替换、可逆建造、库存提示、重复字母与 AVA 查询。浏览器测试在真实 Edge 中验证拖放、点击撤回、提示、晶球分析、过关、手机输入和记录持久化，截图与结果位于 `artifacts/game-*`。其他平台可通过 `GAME_BROWSER` 设置浏览器可执行路径。
